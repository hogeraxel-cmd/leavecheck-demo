# LeaveCheck · demo privada

Demo de **LeaveCheck**, revisión de licencias médicas para empleadores.

**Abrir:** https://hogeraxel-cmd.github.io/leavecheck-demo/ (pide la clave de administrador).

La página está **cifrada** (AES-256-GCM, llave derivada con PBKDF2-SHA256, 600.000 iteraciones): sin la clave, su
contenido no se puede leer, ni siquiera mirando este repositorio. Todos los datos de la demo son ficticios.
